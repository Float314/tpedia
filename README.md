tpedia brings Wikipedia articles directly to your terminal screen, making it extremely easy to browse and find information.

## Usage 

Since it is just an executable, access tpedia via the command.

```bash
tpedia
```

> [!TIP]
> Rename the executable to "Wikipedia" or "wpedia" or whatever you wish to, to make it easy to access the executable
> aka, easing...

## Why? 

Modern web browsers are great, but sometimes you just want to read documentation or learn about a topic from a terminal session.

tpedia aims to provide a simple and pleasant Wikipedia experience for terminal users, minimal Linux installations, and remote SSH environments.

## Dependencies

- nlohmann/json (JSON parsing)
- FTXUI (rendering in terminal)
- cpp-httplib
